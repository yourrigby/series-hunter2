# FrameFinder v25 — QA

## Изменение
- Вместо вертикальной ленты фактов используется матовая панель с сеткой 2×2, соответствующая выбранному референсу.
- Четыре ключевые характеристики выбираются из реальных ответов пользователя. Названия и цвета не фиксируются как текст из референса.
- Все плитки одной высоты в каждой проверенной конфигурации, иконки имеют прозрачность 20%.
- Заголовок содержит иконку кинохлопушки и актуальное число сериалов из каталога. «Ваш вкус по шкалам» и блок совпадений оставлены ниже.

## Автоматические тесты, Chromium
- Разрешения: 320×700, 390×844, 768×1024 и 1440×900.
- Пример с заполненными предпочтениями: 4 факта; две колонки; высоты всех 4 плиток совпадают на каждом разрешении.
- Проверены отсутствие горизонтального переполнения, вылезания текста за края плиток и ошибок JavaScript.
- Дополнительный сквозной сценарий: пройдены все 24 доступных в сценарии вопроса до результата, без ошибок JavaScript.
- Проверена совместимость синтаксиса JavaScript.

Скриншоты: facts-320.png, facts-390.png, facts-768.png, facts-1440.png.

Ограничения: это браузерная проверка Chromium. На физических iOS / Android с Safari / Chrome ручное тестирование ещё не выполнялось. Если пользователь пропустит необязательные вопросы и данных недостаточно, показываются только определённые по ответам факты без придумывания остальных.
