# FrameFinder v25

Сайт для подбора сериалов. В версии v25 блок «Факты о вас» обновлён до сетки 2×2 в общей матовой стеклянной панели.

## GitHub Pages

1. Разместите `index.html` и папку `assets/` в корне репозитория.
2. В GitHub откройте Settings → Pages, выберите Deploy from a branch → `main` / `/ (root)`.
3. Откройте опубликованный адрес сайта.

Для запуска без репозитория можно использовать `framefinder-ui-v25-standalone.html`, где изображения встроены в HTML.
